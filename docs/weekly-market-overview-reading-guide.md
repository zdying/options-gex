# 周度市场总览图读图说明

这份文档说明 `KairAlert Gravity Weekly Market Overview` 图上每个区域的含义，以及如何用它快速理解未来一周的市场结构。

这张图是**市场总览图**，目标不是展示每个标的的详细曲线，而是把指数 ETF、核心权重股、半导体链、风险/避险参考放在同一张图里，观察全市场的结构倾向。

## 1. 顶部标题区

标题示例：

```text
KairAlert Gravity Weekly Market Overview
```

标题下方是基础信息：

```text
Base date 2026-07-10 · Market Structure: Weak Choppy · Score -12
```

含义如下：

- `Base date 2026-07-10`：使用的是 2026-07-10 收盘后的数据。
- `Market Structure: Weak Choppy`：当前市场总结构偏震荡偏弱。
- `Score -12`：市场综合分数。负数偏弱，正数偏强，接近 0 表示拉扯或中性。

右上角的评分环把综合分数映射成 1-10 档，例如：

```text
4/10
Weak
```

它用于快速表达市场总结构强弱。

## 2. 颜色体系

这张图里有两套颜色语义，需要分开理解。

### 红蓝条颜色

红蓝横条表示上下引力分布：

- **红色**：下方引力，也就是 `Down / lower pull`。
- **蓝色**：上方引力，也就是 `Up / upper pull`。

### 分数颜色

凡是显示 `x/10` 的位置，都使用和右上角评分环一致的 1-10 分色阶，包括：

- 右上角评分环。
- 分组卡片底部的 ticker 小标签。

项目采用“红涨绿跌”的视觉习惯：

- 低分偏绿色。
- 高分逐渐过渡到黄/橙/红色。
- 未点亮的分段为灰色。

因此，同样是 `4/10`，在评分环和 ticker 小标签中会使用同一套颜色。

## 3. 四个分组卡片

中间四个卡片分别是：

```text
Index ETF
Mega Cap
Semis
Risk / Hedge
```

### Index ETF

包含：

```text
SPY, QQQ, IWM, DIA
```

用于观察主要指数 ETF 的整体结构。

### Mega Cap

包含核心权重股：

```text
NVDA, AAPL, MSFT, AMZN, META, GOOGL, TSLA
```

用于观察大权重是否形成一致上拉或一致偏弱。

### Semis

包含半导体链：

```text
NVDA, AMD, AVGO, MU, INTC, TSM, SMH, SOXX, SNDK
```

用于观察半导体内部是否共振，还是强弱分化。

### Risk / Hedge

包含风险/避险参考：

```text
TLT, GLD, VIX
```

用于观察避险和波动信号。

## 4. 分组标题和分组 Score

每个卡片标题类似：

```text
Index ETF · Weak Choppy
```

左边是分组名称，右边是分组结构判断：

- `Weak Choppy`：震荡偏弱。
- `Mixed / Neutral`：分化或中性。
- `Strong Choppy`：震荡偏强。

右侧还有：

```text
Score -18
```

这个分数表示该分组内部标的的方向一致性和强弱倾向。负数偏弱，正数偏强，接近 0 表示分化或拉扯。

## 5. 分组红蓝条

每个分组卡片中间有红蓝横条，例如：

```text
Down 59.17%
Up 40.83%
```

含义是：该分组内部标的的平均加权引力里，下方占 59.17%，上方占 40.83%。

这不是涨跌概率，而是当前引力结构的方向倾斜：

- 红色更长：下方引力更重。
- 蓝色更长：上方引力更重。
- 红蓝接近：分组更偏拉扯。

## 6. Pull 结构说明

红蓝条下方左侧会显示：

```text
Pull: downside-heavy
Pull: upside-heavy
Pull: balanced
```

含义如下：

- `Pull: downside-heavy`：该分组整体下方引力更重。
- `Pull: upside-heavy`：该分组整体上方引力更重。
- `Pull: balanced`：上下引力接近，分组更偏拉扯。

这个判断会根据该分组的平均上/下引力比例自动生成，不是手动写死。

## 7. Stronger / Weaker

红蓝条下方右侧会显示：

```text
Stronger: AVGO, INTC · Weaker: None
```

含义是：

- `Stronger`：该分组中结构相对更强的代表标的。
- `Weaker`：该分组中结构相对更弱的代表标的。

如果显示 `None`，表示当前没有足够明显的相对强/弱代表。

## 8. 分组内的小标签

每个分组卡片底部有若干 ticker 小标签，例如：

```text
QQQ 4/10
IWM 3/10
DIA 6/10
```

含义是：每个标的自己的周度结构分数，被映射成 1-10 档。

颜色含义：

- 小标签背景色来自 1-10 分色阶。
- 同样的分数，在右上角评分环和 ticker 小标签中使用同一套颜色。

这些标签用于快速比较同一分组内部谁更强、谁更弱。

## 9. Market Gravity Curve

左下角是标准化后的市场引力曲线：

```text
Market Gravity Curve
```

这张小图不是价格曲线，也不是概率曲线，而是把不同标的的关键引力区统一转换成相对现价距离后，再聚合成的结构曲线。

横轴固定为：

```text
-15%   -10%   -5%   0%   +5%   +10%   +15%
```

含义是：

- `-15%`：相对各自现价下方 15%。
- `0%`：各自现价，也就是相对现价距离为 0。
- `+15%`：相对各自现价上方 15%。

图中有两条线：

- **Core market**：核心市场线，包含 `Index ETF + Mega Cap + Semis`。
- **Risk / Hedge**：风险/避险线，包含 `TLT / GLD / VIX`。

生成逻辑：

1. 每个 ticker 先取自己的关键引力区。
2. 每个关键区用 `distancePct` 转成相对现价距离。
3. 每个 ticker 先按自身最大有效引力做归一化，避免某个标的因为绝对数值过大而主导曲线。
4. 各 ticker 等权聚合。
5. 最后画成 `-15% ~ +15%` 的平滑曲线。

背景颜色：

- 左侧淡红区域：现价下方，也就是 lower pull 区域。
- 右侧淡蓝区域：现价上方，也就是 upper pull 区域。
- 中间橙色虚线：`0%`，也就是各自现价。

读法：

- 核心市场线在左侧峰值更高：核心市场下方引力更集中。
- 核心市场线在右侧峰值更高：核心市场上方引力更集中。
- `0%` 附近峰值高：现价附近拉扯更明显。
- 两侧都有明显峰值：更像区间拉扯，而不是干净单边。
- Risk / Hedge 线抬高：避险或波动相关结构值得注意。

这条曲线提供的是全市场标准化视角，不能直接理解成某个指数的具体价格目标。

## 10. Risk Dashboard

右下角是风险状态面板：

```text
Risk Dashboard
```

它不是逐个点位表，而是对整张图的压缩解读。

常见行包括：

```text
Market
Index Pressure
Mega Cap
Semis
Hedge / Vol
```

含义如下：

- `Market`：市场总体结构。
- `Index Pressure`：指数端主要压力来源。
- `Mega Cap`：核心权重股整体状态。
- `Semis`：半导体链整体状态。
- `Hedge / Vol`：避险和波动参考。

左侧小圆点颜色：

- 红点：偏弱或压力项。
- 蓝点：偏强或上行/波动项。
- 灰点：中性、分化或拉扯项。

## 11. 底部免责声明和水印

图表底部会显示：

```text
Disclaimer: For informational purposes only. Not investment advice.
```

含义是：这张图只用于市场结构观察，不构成投资建议。实际判断仍需要结合 K 线、趋势、成交量、消息和其他指标。

右下角保留 KairAlert 水印，用于标识图表来源。

## 12. 推荐读图顺序

建议按下面顺序阅读：

1. 先看顶部 Market Structure 和右上角评分环，判断全局偏强、偏弱还是拉扯。
2. 看四个分组卡片，确认压力主要来自指数、权重、半导体，还是风险/避险。
3. 看每个分组的红蓝条，判断该分组是上方引力更重还是下方引力更重。
4. 看 `Pull` 结构和 `Stronger / Weaker`，理解分组内部的方向和代表标的。
5. 看 `Market Gravity Curve`，观察核心市场和风险/避险的相对引力分布。
6. 看 `Risk Dashboard`，把图表信息压缩成市场环境判断。

## 13. 使用边界

Market Overview 是市场结构总览图，不是交易信号图。

它适合回答：

- 下周市场整体偏强、偏弱还是拉扯？
- 哪个分组是主要压力来源？
- 哪些标的相对更强或更弱？
- 避险和波动信号是否在增强？

它不适合单独回答：

- 明天一定涨还是跌？
- 应该买入还是卖出某个标的？
- 精确进出场点在哪里？

具体价格区间和关键引力点，应该继续查看对应标的的 `KairAlert Gravity Structure` 个股图。
