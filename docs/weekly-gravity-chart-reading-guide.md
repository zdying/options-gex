# 周度引力图读图说明

这份文档解释周度引力图上每个元素的含义，以及如何用它理解一个标的的短期结构。

## 1. 标题区域

例如：

```text
TSM Weekly Gravity Structure
```

表示这是 TSM 的周度引力结构图。

标题下方通常有一行基础信息：

```text
Base date 2026-07-10 · Spot 434.11 · downward-pull
```

含义如下：

- `Base date 2026-07-10`：使用的是 2026-07-10 收盘后的期权数据。
- `Spot 434.11`：当前使用的现价/基准价格是 434.11。
- `downward-pull`：整体结构偏下方引力，也就是下方牵引更重。

常见结构标签包括：

```text
upward-pull
downward-pull
near-balanced-pull
```

分别表示上方引力更重、下方引力更重、上下引力接近均衡。

## 2. 右上角评分

右上角类似：

```text
4/10
Weak
```

这是把当前标的的周度结构分数转换成 10 档后的结果。

大致含义：

```text
1-3   偏弱
4-6   均衡到轻微方向性
7-10  偏强
```

圆环中间的数字和右侧分数是一致的。

例如：

```text
4/10
Weak
```

表示当前结构不是极端弱，但整体偏弱。

```text
8/10
Very Strong
```

表示当前结构明显偏强。

项目采用“红涨绿跌”的视觉习惯：

- 低分偏绿色。
- 高分逐渐过渡到橙色/红色。

## 3. Weighted Pull Distribution

图上方的红蓝横条表示上下引力比例。

例如：

```text
Down 65.56%
Up 34.44%
```

含义是：在当前周度窗口中，按距离加权后，下方引力占 65.56%，上方引力占 34.44%。

这不是说价格有 65.56% 的概率下跌，而是说：

```text
当前期权结构里，现价下方的牵引更重。
```

横条下方还有：

```text
Weighted skew -0.31 · Raw skew -0.34
```

含义如下：

- `Weighted skew`：距离加权后的上下引力偏斜。
- `Raw skew`：不考虑距离权重的原始上下引力偏斜。

判断方式：

```text
负数：下方引力更重
正数：上方引力更重
接近 0：上下比较均衡
```

## 4. Weighted Gravity Curve

中间主图是整张图最重要的部分。

### 蓝色粗线和浅蓝填充

蓝色粗线表示关键引力区的：

```js
weightedGravity
```

可以理解为：

```text
哪些价格区间对下周价格更有吸附/牵引作用。
```

蓝色峰值越高，表示该 strike 附近的有效引力越强。

浅蓝色填充区域和蓝色粗线使用的是同一批点。

注意：这条蓝色曲线不是完整逐 strike 分布，而是关键引力区摘要曲线。

### 灰色细线

灰色细线表示：

```js
netGravity
```

它保留了引力的正负方向。

判断方式：

- 灰线在零轴上方：正向结构更强。
- 灰线在零轴下方：负向结构更强。

灰色线不是主评分依据，更像是辅助观察 signed structure 的参考线。

### 中间横线

图中的浅灰横线是零轴。

它主要用于判断灰色细线是在正区间还是负区间。

### 橙色虚线

橙色虚线表示当前现价：

```text
Spot 434.11
```

如果现价上方/下方有明显蓝色峰值，就可以看出价格附近有哪些关键吸附区。

## 5. 曲线上的红蓝标注点

曲线上会标出若干最强关键引力点，例如：

```text
400, 410, 420, 430, 440
```

这些是当前结构里最重要的引力区。

颜色含义：

- 红色点：位于 spot 下方。
- 蓝色点：位于 spot 上方。

这些点不是所有 strike，而是 `strongestWeightedGravityZones` 中的关键点。

例如 TSM 图中：

- `420 / 430` 在现价下方附近，是重要下方引力区。
- `440` 在现价上方，是重要上方引力区。
- `400 / 410` 是更远一点的下方引力区。

## 6. 底部三个表格

底部有三个列表：

```text
Upper zones
Lower zones
Near spot
```

### Upper zones

表示现价上方的重要引力区。

例如：

```text
440 (1.36%, w 0.79)
460 (5.96%, w 0.46)
450 (3.66%, w 0.58)
```

每一行含义：

- `440`：strike 价格。
- `1.36%`：距离现价 1.36%。
- `w 0.79`：距离权重是 0.79。

越接近现价，距离权重通常越高。

### Lower zones

表示现价下方的重要引力区。

例如：

```text
420 (-3.25%, w 0.61)
400 (-7.86%, w 0.39)
430 (-0.95%, w 0.84)
```

负的百分比表示该 strike 位于现价下方。

### Near spot

表示离现价较近、同时引力也比较重要的区域。

这个列表最适合观察短期临界区，因为它离当前价格最近。

## 7. 如何读一张图

可以按下面顺序读：

1. 看右上角评分，判断整体偏强、偏弱还是均衡。
2. 看红蓝横条，确认上方引力和下方引力谁更重。
3. 看 spot 线附近有没有明显关键点。
4. 看 `Near spot`，找短期最重要的临界区。
5. 看 `Upper zones` 和 `Lower zones`，判断上方压力/牵引和下方支撑/吸附区。
6. 结合蓝色峰值，判断哪些区间最容易成为价格验证位置。

## 8. TSM 示例

假设一张 TSM 图显示：

```text
Spot 434.11
Down 65.56%
Up 34.44%
Weighted skew -0.31
4/10 Weak
```

可以这样理解：

TSM 当前现价是 `434.11`。  
下方引力占比 `65.56%`，上方只有 `34.44%`，所以整体偏弱。  
关键下方区域集中在 `430 / 420`，其中 `430` 离现价很近，是短期重要拉扯位。  
上方主要看 `440`，如果重新站上并稳定在 `440` 附近，上方结构才会改善。  
如果守不住 `430`，下方 `420` 会成为更重要的验证区。

一句话总结：

```text
TSM 当前不是极端空头结构，但下方引力明显更重；短期关键看 430，站不稳就容易往 420 区域验证，上方改善需要重新靠近并站稳 440。
```

## 9. 重要提醒

这张图不是价格预测，也不是概率图。

它更适合用来描述：

```text
短期价格结构
关键吸附区
上下引力分布
现价附近的临界区域
```

不要把 `Down 65%` 理解成“有 65% 概率下跌”。  
它表示的是当前结构中下方引力的相对占比。
