# KairAlert Gravity Map 最佳实践

## 一、Gravity Map 能告诉你什么

Gravity Map 描述的是当前市场在不同价格区域形成的引力结构。它首先解决的不是“现在该看哪个指标”，而是三个更直接的问题：

- **哪里重要：** 现价上方和下方分别有哪些关键引力区。
- **先看哪里：** 同一方向上有哪些近端、下一层和更远的引力点。
- **路径如何：** 现价与主要目标之间结构密集，还是缺少明显的中间引力。

同一个引力区也不是永远只有一种作用。价格从远处向它运行时，它可以提供目标参考；价格已经到达时，要观察它表现为吸附、压力还是支撑；价格原本就在核心附近时，则要判断市场是否暂时被锁定在这里。

### Gravity Map 上的关键元素

| 元素                 | 含义                                                               |
| :------------------- | :----------------------------------------------------------------- |
| **引力曲线峰值**     | 该价格区间的引力最强，是重要的验证位，价格容易在此停留、反弹或受阻 |
| **上方关键引力区**   | 现价上方引力较集中的位置，价格到达后容易受压，是重要的观察区域     |
| **下方支撑引力区**   | 现价下方引力较集中的位置，价格下跌后可能在此放慢或获得支撑         |
| **橙色虚线（Spot）** | 快照时刻的现货价格，用于判断当前价格相对引力结构的位置             |
| **青色虚线（VWAP）** | 同一时刻的成交量加权均价，用于观察日内价格是否重新回到均价一侧     |

## 二、Gravity Map 与 K 线、VWAP、均线的配合

Gravity Map 先给出关键结构，K 线、VWAP 和均线再用来观察价格正在向哪一侧运行，以及价格进入引力区后产生了什么反应。

- 价格站在 VWAP 上方、MA5 位于 MA15 上方时，上方引力区的参考意义通常更高。
- 价格跌到 VWAP 下方、MA5 位于 MA15 下方时，下方引力区的参考意义通常更高。
- 价格已经处在强引力核心附近时，VWAP 和均线可能频繁交叉。此时先判断价格能否真正脱离核心，而不是跟随每一次交叉改变方向。

实际使用时，顺序始终是：**先用 Gravity Map 找结构，再用价格行为确认方向，最后回到 Gravity Map 寻找该方向上的目标和路径。**

## 三、七种典型用法

不要看到峰值就一律理解成“目标”或“支撑”。现价所处的位置不同，引力结构承担的角色也不同。

| 当前状态                                 | Gravity Map 的主要用法            | 对应案例 |
| :--------------------------------------- | :-------------------------------- | :------- |
| 价格获得比较明确的方向，前方有多个引力点 | 从近到远安排观察目标              | AMD      |
| 价格已经进入目标区域                     | 观察该区域被接受还是形成压力/支撑 | INTC     |
| 价格本来就在最强核心附近                 | 判断是否处于强吸附状态            | GLD      |
| 价格从强核心附近脱离                     | 寻找脱离后的下一层参考            | SPY      |
| 价格偏离仍然稳定的核心                   | 等待回归条件，而不是提前猜回归    | MSFT     |
| 现价与目标之间缺少中间峰值               | 识别可能快速运行的低引力通道      | SNDK     |
| 临近收盘，价格仍围绕持续的强核心运行     | 观察尾盘 Pin（执行价吸附）        | MSFT     |

### 案例一：AMD — 方向转弱后的下方目标

**日期：2026-07-20**

这一天 AMD 两次出现了相似的过程：价格跌到 VWAP 下方，短线均线转弱，然后沿着引力图中的下方点位逐层运行。

#### 开盘地图：先确定上下结构

开盘时 AMD 现价为 $512.67。上方 $520 是明显的引力区，下方 $500 是更远的强引力区。现价位于二者之间时，引力图只告诉我们两侧分别有哪些重要区域，并不能单独决定价格先走哪一边。

开盘后价格先向上运行，09:36 触及 $520.57，09:44 最高到 $522.50。价格进入 $520 引力区后，这里可能开始表现为压力，此前的多头可以开始关注止盈和回撤风险。

#### 第一次信号：09:49

![AMD 第一次信号](https://kastatic.pages.dev/best_practices/scenario_amd_0720_signal1.svg)

09:49，价格由 $520 上方回落到 $518.33：

- K 线收在 VWAP（$518.76）下方；
- MA5 同时跌到 MA15 下方；
- 价格开始离开刚刚测试过的 $520 区域。

到这个时刻，K 线、VWAP 和均线才共同给出短线转弱的背景。再回到 09:49 的 Gravity Map 下方结构：

- **$515：最近的观察区域。** 它是现价下方最近的局部引力峰，同时作为 5 的倍数，也可能受到心理价位和集中挂单的影响。它的引力弱于 $512.5 和 $500，因此更适合作为第一处路径观察点，而不是主要目标。
- **$512.5：下一层引力点。** 如果价格进入 $515 一带仍没有明显放慢，可以继续观察这里。
- **$500：更远的强引力区。** 结构很突出，但距离较远，需要价格持续保持弱势，且近端位置陆续被穿过以后再提高其参考意义。

价格随后在 09:51 进入 $515 一带，09:55 又运行到 $512.5 附近。这里 Gravity Map 提供的价值很具体：方向由价格行为确认以后，它把“下方还有多少空间”和“先看哪里、再看哪里”变成了一张有层次的地图。

如果价格在途中重新站稳 VWAP，MA5 也回到 MA15 上方，就不能继续机械沿用原来的向下顺序，需要重新读取当时的价格和引力结构，需要重点评估做空的风险。

#### 第二次信号：10:40

![AMD 第二次出现相同观察方法](https://kastatic.pages.dev/best_practices/scenario_amd_0720_signal2.svg)

10:22 至 10:35，AMD 从 $509 附近反弹，10:35 最高达到 $518.73。随后：

- 10:36，价格再次跌回 VWAP 下方；
- 10:40，MA5 再次跌到 MA15 下方；
- 当时的下方结构依次为 $512.5、$507.5 和更远的 $500。

后续价格先经过 $512.5 一带，再继续向 $507.5 附近运行。

**这一用法的关键：**

> K 线、VWAP 和均线先帮助判断价格正在向哪一侧运行；Gravity Map 再负责列出这一侧最值得观察的价格区域。最近的有效引力点优先，只有方向持续、近端区域被经过以后，才逐步观察更远的强引力区。

### 案例二：INTC — 到达上方目标后的价格反应

**日期：2026-07-20**

INTC 开盘现价为 $97.75，Gravity Map 上方最明显的区域位于 $100。开盘后价格位于 VWAP 上方，短线均线保持偏强，价格方向和上方引力区位于同一侧，因此 $100 成为当时最直接的上方参考。

09:37，价格已经进入 $100 附近，随后最高达到 $100.97。此时的观察重点应该转向价格能否留在这一带、是受阻还是一路继续突破。

![INTC 到达 $100 后跌回 VWAP 下方](https://kastatic.pages.dev/best_practices/scenario_intc_0720_signal1.svg)

09:52，价格回落到 $99.15：

- 价格跌到 VWAP（$99.72）下方；
- MA5（$100.04）跌到 MA15（$100.06）下方；
- 此前的上行动能没有继续维持。

因此，$100 在价格接近过程中承担的是上方目标角色；价格进入该区域后未能站稳，它又成为需要重新观察的上方压力。相反，如果价格能够持续站在该区域和 VWAP 上方，均线也保持偏强，就应继续观察该区域是否正在被价格接受，上方是否会有新的更强的引力区出现。

**这一用法的关键：**

> 进入引力区以后，下一步由价格行为决定。继续停留、反复围绕核心运行，和快速回到 VWAP 另一侧，代表的是不同状态；不要因为目标已经得到验证，就自动推断后面一定反转或一定突破。

### 案例三：GLD — 强引力核心附近的吸附

**日期：2026-07-20**

GLD 是一个比较清晰的强吸附案例。开盘现价为 $367.93，最突出的引力核心就在 $368 附近；盘中连续快照里，$365 至 $372 一带始终保持密集结构，价格也长时间围绕该区域运行。

![GLD 在 $368 强引力核心附近保持吸附](https://kastatic.pages.dev/best_practices/scenario_gld_0720.svg)

判断强吸附，不能只看“这里有一个很高的峰值”。至少要同时检查四件事：

1. **现价已经位于核心附近。**
   价格不是从远处向目标运行，而是一开始就处在最强峰值或密集峰值区域内。

2. **核心相对突出。**
   周围虽然可能还有其他峰值，但当前核心在强度和密集程度上占据主导，价格没有一个同等清晰的远端目标。

3. **结构能够持续。**
   连续快照中，核心仍停留在同一片价格区域，没有快速迁移到另一侧。

4. **多次离开都没有形成持续位移。**
   短暂跌破或站上 VWAP、MA5 与 MA15 的交叉，都没有把价格真正带离核心区域。

GLD 在 10:00 后曾跌到 $367 下方，VWAP 和均线也一度同步转弱，但价格没有继续扩大与 $368 核心的距离；到 10:40，价格又回到 $367.9 附近。这里的均线交叉发生在强吸附区内部，作用主要是帮助观察价格有没有真正脱离，而不是每交叉一次就建立一个新的方向判断。

**这一用法的关键：**

> “现价贴近核心、核心明显且持续、多次脱离都无法延续”共同构成强吸附。只看到峰值很高，或者只看到价格碰巧在峰值附近，都不足以单独确认这种状态。

### 案例四：SPY — 从强引力核心脱离

**日期：2026-07-20**

SPY 开盘现价为 $747.62，最强引力集中在 $747 附近。开盘后的约 15 分钟里，价格主要在 $747.5 至 $748.6 之间震荡，VWAP 贴近价格，符合现价被核心区域锁定的特征。

处在这种结构中时，一次短暂越过 VWAP 并不足以说明已经出现方向。真正需要观察的是：价格能否离开核心、能否在核心外保持，以及离开以后前方是否出现新的引力参考。

![SPY 脱离强引力区后的下方参考](https://kastatic.pages.dev/best_practices/scenario_spy_0720.svg)

09:46 至 09:48 出现了三项变化：

- 09:46，价格收于 VWAP 下方（$748.02 < $748.06），开始尝试离开原来的锁定区域；
- 09:48，MA5（$748.08）跌到 MA15（$748.18）下方，短线动能开始配合；
- Gravity Map 下方依次存在 $745 和 $740 两层结构，脱离后成为重要的参考区域。

这时先观察最近的 $745；如果价格重新回到 $747 核心并站稳 VWAP，脱离判断就需要降级。只有价格继续处在核心下方、$745 又没有形成有效缓冲时，才进一步提高 $740 的参考意义。

SPY 和 GLD 的区别也由此变得清楚：GLD 的多次方向尝试都回到核心，重点是识别吸附；SPY 则出现了价格离开核心、VWAP 与均线转弱、下方目标逐层展开的组合，重点转为观察脱离。

**这一用法的关键：**

> 强引力区内的波动不等于有效脱离。价格位置、VWAP、均线和核心外的下一层结构需要一起看；离核心越近，越要防止把区间内部的摆动误认为新趋势。

### 案例五：MSFT — 偏离核心后的回归

**日期：2026-07-13**

MSFT 开盘现价为 $389.88，$390 是当天持续稳定的主要引力核心。价格开盘后却快速向下偏离：

- 10:08 收于 $385.05；
- 低于 VWAP（$387.89）；
- MA5（$386.07）低于 MA15（$386.88）。

此时虽然上方 $390 仍然突出，但价格行为并不支持立即观察回归。稳定核心提供的是一个保留在地图上的重要位置，而不是要求价格马上回去的理由。

![MSFT 站回 VWAP 后向 $390 核心回归](https://kastatic.pages.dev/best_practices/scenario_msft_0713.svg)

到 10:48，价格状态发生变化：

- 收盘价 $387.48，重新站到 VWAP（$386.93）上方；
- MA5（$386.52）重新回到 MA15（$386.11）上方；
- $390 仍然是当时最突出的核心，没有在价格偏离期间消失或迁移。

这时价格方向重新与 $390 核心一致，$390 才从“仍需保留观察的结构”转为有意义的回归目标。10:54，价格进入 $390 附近；11:00 收于 $389.74。

这个案例里，三个条件缺一不可：

1. 价格确实与主要核心形成了偏离；
2. 核心在偏离过程中仍保持稳定；
3. K 线重新站回 VWAP，短线均线也开始转向核心一侧。

如果核心已经迁移，或者价格行为始终没有重新指向核心，就不能继续把原来的核心作为当前回归目标。

**这一用法的关键：**

> 偏离本身不是回归信号，并不代表一定会回归。Gravity Map 用来确认核心是否仍然存在，K 线、VWAP 和均线用来确认价格是否已经开始朝核心方向移动。

### 案例六：SNDK — 低引力通道中的快速运行

**日期：2026-07-17**

Gravity Map 不只用来看峰值，也要看峰值之间有什么。现价与主要目标之间如果缺少足够强的中间结构，价格获得方向后，途中能够形成停顿的区域会更少。

09:47，SNDK 的价格状态开始偏强：

- 收于 $1347.37，高于 VWAP（$1345.49）；
- MA5（$1340.62）高于 MA15（$1340.11）；
- 上方 $1390 是最突出的引力区。

![SNDK 通过低引力通道快速运行到 $1390](https://kastatic.pages.dev/best_practices/scenario_sndk_0717.svg)

从现价到 $1390 之间并非完全没有峰值，但中间结构明显偏弱。其中 $1370 一带的峰值强度只有 $1390 的约三成，难以形成与主要目标同等级的缓冲。

随后价格快速通过这段区域，09:57 最高达到 $1392.88，从方向确认到进入 $1390 一带约用了 10 分钟。

低引力通道的判断重点是**相对强弱**，不是看到两个峰值之间有空白就直接推断价格会加速：

- 先确认价格已经站到 VWAP 的目标一侧，均线方向也相互配合；
- 再比较主要目标与沿途峰值，而不是只看沿途有没有峰值；
- 如果中间出现新的强峰值，或者价格重新失去方向，原来的通道判断需要更新。

**这一用法的关键：**

> 引力峰值帮助定位终点，峰值之间的强弱差异帮助理解路径。主要目标突出、沿途结构明显较弱时，价格可能更快地完成这一段运行。

### 案例七：MSFT — 尾盘 Pin（执行价吸附）

**日期：2026-07-20**

当日到期的引力结构中，如果同一个强核心在下午持续存在，价格又始终无法形成有效脱离，临近收盘时可能逐渐收窄波动，并重新向该核心靠拢。这种现象可以称为尾盘 Pin，也就是价格在收盘前被吸附在某个执行价区域附近。

MSFT 当天上午快速上行到 $402.5 一带。13:00 以后，$402.5 始终是现价附近最强的引力核心，价格大部分时间也保持在 $400.15 至 $402.49 之间。

![MSFT 尾盘向 $402.5 核心收敛](https://kastatic.pages.dev/best_practices/case_msft_0720_tail_pin.svg)

三个快照反映了同一条持续结构：

- **13:00：** Spot 为 $401.36，$402.5 已经是最强核心；
- **15:00：** Spot 短暂回落到 $400.62，但 $402.5 核心没有迁移；
- **15:59：** Spot 回到 $402.30，重新收敛到 $402.5 核心附近。

这里重点观察的不是某一根 K 线，而是“核心持续存在、价格多次偏离都没有延续、尾盘重新靠近”这三个特征。如果价格已经持续远离原核心，或者主要引力结构迁移到其他位置，就不再按尾盘 Pin 观察。

**这一用法的关键：**

> 尾盘 Pin 是持续强核心对价格的收敛作用。核心越稳定，价格越难形成有效脱离，临近收盘时的参考意义越高。

## 四、盘中观察流程

不同场景的使用顺序是一致的：识别结构、确认方向、逐层观察，再判断价格到达后的反应。

### 第一步：识别当前引力结构

先看 Spot 与主要引力区的位置。

- 主峰突出时，将其列为候选目标；
- 多个相邻峰集中时，按一个区域观察；
- 峰值分散、上下优势接近时，暂不选择方向；
- Spot 已在核心附近时，重点观察吸附和脱离。

### 第二步：用价格行为确认运行方向

- 价格站在 VWAP 上方，MA5 位于 MA15 上方时，优先观察上方候选目标；
- 价格跌到 VWAP 下方，MA5 位于 MA15 下方时，优先观察下方候选目标；
- K 线、VWAP 和均线方向不一致时，继续等待。

### 第三步：沿目标方向逐层观察

- 先观察当前方向上最近的引力区。
- 价格穿过后，再观察下一个引力区。
- 中间没有明显引力区时，价格可能运行得更快。
- VWAP、均线或引力结构发生变化时，重新判断。

### 第四步：到达目标后重新判断

- 围绕核心持续运行：按吸附状态观察。
- 进入上方区域后快速回落并跌破 VWAP：该区域开始表现为压力。
- 进入下方区域后止跌并站回 VWAP：该区域开始表现为支撑。
- 穿过当前区域并保持原有方向：继续观察下一层引力点。
