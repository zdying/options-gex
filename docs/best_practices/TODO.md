# Gravity Map 最佳实践后续研究

## 三个候选权重过滤器

以下内容暂不加入最佳实践正文。需要扩大历史样本、明确判定标准后，再决定如何对外表达。

### 1. 引力结构清晰度

研究单一核心、多个相近峰值和频繁迁移等结构，对目标区域参考权重的影响。

待解决：

- 如何量化核心引力区的集中度和领先程度。
- 如何区分“明确目标”“多点拉扯”和“暂时没有有效方向”。
- 结构不清晰时，是否只降低目标权重，而不强行给出方向。

### 2. 多周期引力区共振

研究 Today、Near、All 等不同周期是否指向同一价格区域。

当前初步观察：多周期重合更可能提高该区域的重要性和持续性，但不直接提供上涨或下跌方向，也不保证价格一定突破或反转。

待解决：

- 至少需要几个周期重合才算有效共振。
- 不同周期应如何分配权重。
- 共振区域允许多大的价格偏差。
- 共振主要增强目标稳定性、到达概率，还是到达后的反应强度。

### 3. 开盘结构与盘中实时结构的一致性

研究开盘引力曲线与盘中实时引力曲线保持一致或发生变化时，如何调整目标区域的参考权重。

当前初步观察：开盘与实时核心一致时，关键区域通常更稳定；盘中出现新核心时，不应仅凭一次快照立即替换原有结构。

待解决：

- 新核心需要持续多长时间才视为有效迁移。
- 是否需要价格、VWAP、MA 或 K 线同步确认。
- 原核心减弱、新核心增强和价格已经开始移动，三者应按什么顺序判断。
- 如何区分短暂扰动与真正的结构迁移。

## 后续验证要求

- 扩大到更多交易日和不同类型标的。
- 将“进入目标区域”定义为动态价格带，而不是精确命中单一价格。
- 分开统计目标到达前的方向与路径，以及到达后的吸附、拒绝、突破和角色转换。
- 确认三个过滤器增加的是哪一种权重，避免把“区域更重要”误写成“方向更确定”。
